# Hero background media — placeholders to replace

This folder is empty on purpose. Add your own licensed, royalty-free assets
with these exact filenames (already wired up in `components/landing/hero.tsx`):

- `hero-courthouse.mp4` — cinematic looping video (courthouse exterior,
  corridor, gavel, law books, or the Lady Justice statue). Keep it under
  ~8MB and silent; the component mutes it automatically.
- `hero-fallback.jpg` — a high-resolution still of the same subject. Used
  as the `poster` while the video loads, and as the fallback if video
  playback fails or is unsupported.

Suggested royalty-free sources: Pexels, Pixabay, Storyblocks
(search "courthouse", "supreme court India", "gavel", "law books",
"lady justice statue", "legal documents").
